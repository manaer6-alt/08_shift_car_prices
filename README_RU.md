# Прогноз стоимости автомобилей

Соревновательный проект по оценке цены подержанного автомобиля по характеристикам объявления и тексту заголовка. Решение объединяет табличные модели, текстовые признаки, статистики и поиск похожих автомобилей.

## Результаты

Итог соревнования: **2-е место**.

| Оценка | MAPE |
|---|---:|
| Финальная отправка на лидерборд | **12.66%** |
| Вложенная OOF-оценка ансамбля после калибровки | **11.47%** |
| Лучший одиночный CatBoost на holdout | **12.13%** |
| Ridge baseline на holdout | **13.82%** |

Ансамбль оказался лучше каждой отдельной базовой модели. Для выбора состава и калибровки использовались out-of-fold прогнозы.

## Ключевые решения

- Удалён признак `Предложение`: он был заполнен во всём train, отсутствовал в test и коррелировал с ценой на 0.9938.
- Целевая переменная преобразована логарифмически, качество измерялось через MAPE.
- Предобработка выполнялась отдельно внутри каждого фолда.
- Проверен сдвиг распределений между train и test.
- Объединены модели с разными источниками сигнала.

## Состав ансамбля

- CatBoost с признаками заголовка и иерархии автомобиля.
- Ridge на one-hot признаках.
- Целевые статистики, рассчитанные без утечки между фолдами.
- TF-IDF-модель по тексту объявления.
- Поиск ближайших сопоставимых автомобилей.
- Условная калибровка при расхождении прогнозов.
